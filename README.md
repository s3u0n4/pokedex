# 포켓몬 도감

몬스터볼 테마의 전국도감 웹페이지입니다. 1~9세대 포켓몬 1025마리와 리전폼 58종을 한국어로 보여줍니다.

**배포 주소: https://pokedex-five-chi-66.vercel.app**

주소 끝에 `#번호`를 붙이면 그 포켓몬의 상세 화면이 바로 열립니다. 예: [`#25` 피카츄](https://pokedex-five-chi-66.vercel.app/#25)

## 기술

| 구분 | 사용 기술 |
|---|---|
| 화면 | React 19, TypeScript (strict) |
| 빌드 | Vite |
| 배포 | Vercel |
| 데이터 | [PokeAPI](https://pokeapi.co) (REST API, GitHub CSV, 스프라이트), [Smogon 세트](https://data.pkmn.cc) |
| 저장 | localStorage 캐시 (목록·기술 데이터) |
| 폰트 | Jua, Noto Sans KR (Google Fonts) |

서버(백엔드)는 없습니다. 데이터는 모두 브라우저에서 PokeAPI 등에서 직접 받습니다.

## 기능

### 목록
- 전국도감 1025마리를 카드로 보여주고, 리전폼은 원래 포켓몬 카드 바로 뒤에 나옵니다.
- 한국어·영어 이름이나 번호로 검색할 수 있습니다.
- 세대(1~9)와 타입(18종)으로 거를 수 있습니다.
- 키보드: `/`로 검색창, 상세 화면에서 ←·→로 이전/다음 포켓몬, Esc로 닫기

### 상세 화면
- **기본 정보**: 공식 일러스트(이로치 전환), 분류, 타입, 도감 설명, 키·몸무게·성비
- **암수 모습**: 성별에 따라 모습이 다른 포켓몬은 수컷·암컷 그림을 나란히 보여줍니다.
- **타입 상성**: 받는 피해(4배~무효)와 자속 기술로 잘 때리는 타입
- **특성**: 숨겨진 특성 표시, 특성 설명
- **종족값**: 막대그래프와 합계
- **진화**: 단계별 진화 트리와 진화 조건. 레벨, 아이템, 친밀도, 시간대, 통신교환 같은 특수 조건도 보여주고, 리전폼으로 진화하는 경우는 따로 나눠 보여줍니다.
- **리전폼**: 알로라·가라르·히스이·팔데아 모습의 타입, 특성, 능력치(원래 모습과 비교), 진화 방법
- **진화 기믹**: 메가진화(메가스톤), 거다이맥스, 원시회귀, 울트라버스트, 무한다이맥스
- **추천 기술 배치**: Smogon 룰별 세트(기술, 도구, 성격, 노력치, 테라스탈 타입). Smogon 세트가 없는 포켓몬은 능력치와 배울 수 있는 기술로 자동 추천합니다.
- **기술 목록**: 게임별로 레벨업, 기술머신(TM/HM/TR 번호), 알 기술, 기술 가르침

### 디자인
- 빨간 헤더, 검은 띠와 가운데 흰 버튼, 카드의 몬스터볼 워터마크로 몬스터볼 테마를 살렸습니다.
- 모바일에서는 상세 화면이 아래에서 올라오는 시트로 열립니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버: http://localhost:5173
npm run build      # 타입 검사 후 dist/에 빌드
npm run preview    # 빌드 결과 확인
```

## 구조

```
src/
  App.tsx          검색·필터 상태, 주소(#번호) 라우팅, 키보드
  types.ts         앱 데이터 타입과 PokeAPI·Smogon 응답 타입
  lib/             상수, 유틸리티, 공용 데이터 저장소
  api/             목록, 상세, 기술, 한국어 이름 데이터 로딩
  components/      목록 화면과 상세 화면 섹션
legacy/index.html  React로 옮기기 전의 단일 HTML 버전
```

## 알려진 한계

- 9세대 일부는 한국어 도감 설명이 없어서 영어로 나옵니다.
- 거다이맥스 전용 기술(G-Max 기술)은 데이터가 없어서 표시하지 않습니다.
- 타입 상성은 특성(부유 등)과 테라스탈을 반영하지 않습니다.
- PokeAPI에서 퍼퓨돈(916)의 성비가 수컷 100%로 잘못 나옵니다.
